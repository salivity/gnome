Batch Rename Multiple Files in GNOME Files

GNOME Files, also known as Nautilus, includes a built-in batch renaming tool that allows users to quickly organize and rename multiple files simultaneously. By selecting multiple items and accessing the rename dialog, users can leverage pattern matching to perform find-and-replace operations, insert sequential numbering, or apply automated metadata templates. This article explains how to access and utilize these pattern-matching features to rename multiple files efficiently without third-party utilities or command-line scripts.

Accessing the Batch Rename Tool

To initiate batch renaming in GNOME Files:

  1. Open the folder containing the files you wish to modify.
  2. Select the target files by dragging a selection box, holding Ctrl while clicking specific files, or pressing Ctrl + A to select all files.
  3. Right-click any of the selected files and select Rename..., or simply press the F2 key.

A dialog window will appear displaying a list of your selected files along with two primary pattern-matching modes at the top: Rename using a template and Find and replace text.

Renaming Using Templates

The template feature allows you to build custom naming structures by combining static text with dynamic pattern variables.

  • Pattern Tags: Click the Add button in the template field to insert dynamic variables. Available tags include [Original file name] and various sequential numbering formats (e.g., 1, 2, 3, 01, 02, 03, or 001, 002, 003).
  • Metadata Support: Depending on the file type, additional metadata tags may be available, such as creation date or track details for audio files.
  • Custom Formatting: You can type custom text around these tags. For example, entering Vacation_[Original file name]_[+1] will retain the existing filename while prepending a prefix and appending an ascending number.

Find and Replace Pattern Matching

If you need to edit common patterns across existing file names, switch to the Find and replace text option:

  • Existing Text: Enter the exact characters, words, or symbols you want to locate across the selected files.
  • Replace With: Enter the replacement string. Leaving this field blank effectively strips the matched text from the filenames.
  • This mode is particularly useful for removing unwanted characters, changing separators (such as swapping underscores for hyphens), or replacing default camera prefixes.

Live Preview and Execution

Below the pattern configuration options, GNOME Files displays a real-time side-by-side preview. The left column shows the original file names, and the right column shows the proposed changes based on your current pattern. This allows you to verify that formatting, numbering orders, and file extensions remain intact before committing changes.

Once the preview matches your desired structure, click the Rename button in the upper-right corner to apply the changes to all selected files immediately.
