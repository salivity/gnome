Configure Drawing Tablet Pressure in GNOME

The GNOME desktop environment provides native support for graphics tablets, allowing digital artists and designers to adjust stylus tip sensitivity, customize pressure curves, and configure physical stylus buttons directly from the system settings. By integrating hardware abstraction through libwacom and input handling through libinput, GNOME ensures seamless compatibility across both X11 and Wayland display servers while providing both graphical and command-line interfaces for tablet tuning.

GNOME Control Center Stylus Settings

GNOME includes a dedicated Drawing Tablet (or Wacom Tablet) panel within the standard GNOME Control Center. When a supported tablet is connected, this panel detects the device and any associated styli automatically.

Within this interface, navigating to the stylus settings reveals configuration options for:

  • Tip Pressure Sensitivity: A slider allows users to adjust the stylus feel from "Soft" to "Firm." Setting the slider toward "Soft" requires minimal physical force to register full pressure, which reduces hand fatigue. Moving it toward "Firm" requires more deliberate force, preventing accidental strokes during fine line work.
  • Button Assignments: Stylus barrel buttons can be mapped to standard mouse actions (such as right-click or middle-click) or specific keyboard shortcuts.
  • Eraser Tip: If the stylus features an eraser tip, its sensitivity and pressure threshold can be calibrated independently from the drawing tip.

Underlying Backend: libinput and libwacom

GNOME relies on libwacom to recognize tablet dimensions, aspect ratios, stylus types, and button layouts. Event processing and raw pressure reading are managed by libinput.

When you adjust the tip sensitivity slider in GNOME's graphical interface, the desktop calculates a cubic Bézier curve to translate raw pressure values sent by the hardware into the adjusted pressure values sent to applications. This provides a smooth transition across pressure levels rather than an abrupt linear response.

Fine-Tuning via GSettings and dconf

For users requiring deeper customization than the graphical slider provides, GNOME stores input settings in gsettings. You can view and edit these tablet configurations programmatically or through the terminal:

  1. List available tablet settings: 
    gsettings list-recursively org.gnome.desktop.peripherals.tablet
  2. Locate stylus-specific properties under: 
    org.gnome.desktop.peripherals.stylus

Using dconf-editor or gsettings, you can inspect how GNOME binds specific stylus serial numbers to individual configuration profiles, ensuring multi-pen setups maintain distinct pressure thresholds and button bindings.

Interaction with Creative Applications

While GNOME establishes the desktop-wide baseline for stylus behavior, most creative software—such as Krita, GIMP, and Blender—features dedicated internal pressure curve editors.

GNOME delivers the calibrated input stream to these applications via standard Wayland tablet protocols or the X11 XInput2 extension. Digital art applications can then apply secondary Bézier curves on top of GNOME’s system curve, allowing artists to tailor pressure response differently for specific tasks like inking, blending, or sculpting without modifying their global desktop configuration.
