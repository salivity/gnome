Track CPU Memory and Disk in GNOME System Monitor

GNOME System Monitor is a core utility for Linux desktop environments that provides real-time visualization and management of hardware resources. This article details the specific features available within the application to track and analyze processor (CPU) performance, system memory (RAM) and swap allocation, and disk storage capacity and activity.

CPU Tracking Features

GNOME System Monitor tracks central processing unit activity across two primary interfaces: the Resources tab and the Processes tab.

  • Multi-Core History Graphs: Located in the Resources tab, the CPU history section renders real-time, color-coded line graphs tracking overall processor activity. If the system uses a multi-core or multi-threaded CPU, each logical core is plotted independently alongside an aggregate utilization percentage.
  • Per-Process CPU Metrics: In the Processes tab, users can view real-time CPU percentage consumption for individual tasks. The list can be sorted dynamically by clicking the "% CPU" column header, allowing users to immediately identify resource-heavy applications.
  • Process Priority and Control: Users can right-click any process consuming excessive CPU cycles to alter its priority (nice value) or terminate, kill, stop, or resume it directly from the interface.

Memory and Swap Tracking Features

System memory monitoring is split between dynamic historical usage graphs and granular per-process allocations.

  • Memory and Swap History: The Resources tab features a rolling graph that tracks physical RAM and Swap usage simultaneously. The display provides live quantitative figures, showing exact amounts of consumed memory versus total available capacity (e.g., "4.2 GiB of 15.5 GiB") alongside the percentage used.
  • Per-Process Memory Inspection: Within the Processes tab, the "Memory" column displays the physical RAM occupied by each running application.
  • Detailed Memory Maps: Advanced users can right-click an individual process and select "Memory Maps" to view a breakdown of virtual memory allocations, shared libraries, heap, and stack usage for that specific task.

Disk Utilization Features

GNOME System Monitor separates disk tracking into total partition space utilization and individual read/write operations.

  • File Systems Tab: This dedicated tab displays a comprehensive table of all mounted storage devices, partitions, and external drives. For each entry, the application details:
    • Device: The storage node (e.g., /dev/nvme0n1p2).
    • Directory: The designated mount point (e.g., / or /home).
    • Type: The file system format (e.g., ext4, btrfs, or xfs).
    • Total, Available, and Used Space: Quantitative byte values for storage capacity.
    • Visual Bar Graphs: Color-coded percentage bars indicating how full each partition is.
  • Disk Read and Write Rates: Depending on the GNOME version and column configuration in the Processes tab, users can enable "Disk Read Total", "Disk Write Total", or current read/write rate columns to monitor which applications are generating the most input/output (I/O) traffic.
