GNOME Touch Gestures for Workspace Switching

The GNOME desktop environment provides native, fluid touch and touchpad gestures that allow users to seamlessly transition between active workspaces. Built on modern display server architecture and the libinput library, GNOME delivers direct 1:1 tracking, meaning workspace transitions directly mirror the physical movement and speed of the user's fingers. This article explains how GNOME implements these gestures, the hardware and software requirements needed to use them, and the specific touch inputs required for navigation.

The Underlying Technology: Wayland and libinput

GNOME’s touch gesture system relies heavily on the Wayland display protocol and the libinput input-handling library. Unlike older X11 sessions, Wayland allows the window manager (Mutter) to receive raw multi-touch events directly. This direct communication enables true 1:1 physical tracking. As you move your fingers across a touchpad or touchscreen, the desktop environment moves the workspace view concurrently, allowing gestures to be paused, reversed, or completed smoothly mid-motion.

Touchpad Gestures for Workspaces

Beginning with GNOME 40, the desktop adopted a horizontal spatial model where workspaces are arranged in a continuous horizontal strip. Touchpad navigation takes advantage of this layout through three-finger gestures:

  • Switching Workspaces: Swiping horizontally with three fingers moves between adjacent workspaces. Swiping three fingers from right to left moves to the workspace on the right, while swiping from left to right moves to the workspace on the left.
  • Activities Overview Integration: Swiping upward with three fingers opens the Activities Overview, displaying all open windows and the workspace strip. A second upward swipe reveals the application grid. Swiping downward with three fingers returns to the active workspace.

Touchscreen Gestures

For laptops with touch-enabled screens, 2-in-1 convertibles, and tablets, GNOME translates these multi-finger interactions directly to screen surfaces:

  • Three-Finger Screen Swipe: Placing three fingers on the screen and dragging horizontally switches between the active workspaces with the same 1:1 direct tracking seen on touchpads.
  • Edge Gestures and Touch Controls: Users can also bring up the workspace switcher by swiping up from the bottom edge of the display to access the Overview, where workspaces can be selected directly with a single tap.

System Requirements and Compatibility

To ensure touch gestures for workspace switching function properly:

  • Display Server: The session must be running Wayland. While basic gestures can sometimes be emulated on X11 through third-party utilities, native 1:1 gestures are exclusive to Wayland sessions.
  • Hardware Support: The device must feature a precision touchpad or a multi-touch-capable touchscreen recognized by the Linux kernel and libinput.
  • Out-of-the-Box Configuration: Modern distributions shipping GNOME (such as Fedora, Ubuntu, and Arch Linux) enable these gestures by default, requiring no extra configuration or third-party extensions to function.
