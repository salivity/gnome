How Orca Screen Reader Works in GNOME Desktop

Orca is the default screen reader in the GNOME desktop environment, providing visually impaired users with access to graphical applications through speech synthesis and refreshable braille. It acts as an intermediary between the user and the operating system, translating visual interfaces into auditory and tactile output. By integrating with core Linux accessibility frameworks, Orca tracks system focus, reads text, describes interface controls, and allows full navigation of the GNOME environment without requiring sight.

At the core of Orca's functionality is the Assistive Technology Service Provider Interface (AT-SPI2). AT-SPI2 is the standard framework used on Linux to expose accessibility information from applications to assistive technologies. When a user runs GNOME, applications built with UI toolkits like GTK automatically generate an accessibility tree—a parallel hierarchy of the graphical interface containing metadata about every button, text field, window, and menu. Orca communicates with this tree over the D-Bus system message bus, enabling it to query the roles, states, labels, and values of desktop elements in real time.

Orca monitors user interactions and system events to determine what to present. When a user navigates using keyboard shortcuts, the mouse, or specific screen-reading review keys, Orca intercepts these inputs and listens for focus-change events emitted by the active application or GNOME Shell. For example, when focus shifts to a checkbox, Orca queries AT-SPI2 for the control's name, its role (checkbox), and its current state (checked or unchecked), then formats this information into coherent output.

To deliver auditory feedback, Orca does not generate audio directly; instead, it relies on Speech Dispatcher, an intermediary abstraction layer for speech synthesis. Speech Dispatcher routes Orca’s text to an installed Text-to-Speech (TTS) engine, such as eSpeak-NG or Voci. For tactile output, Orca interfaces with BRLTTY (Braille TTY), which drives physical, refreshable braille displays and translates on-screen content into standardized braille cells.

Orca is embedded into GNOME's Universal Access infrastructure, allowing users to toggle it instantly via the shortcut Super + Alt + S or through the desktop settings menu. Because it is written primarily in Python, Orca can utilize specialized application scripts that tailor navigation and reading behaviors for complex programs, such as web browsers, office suites, and terminals, ensuring consistent accessibility across the entire GNOME ecosystem.
