Managing GPG and SSH Keys with GNOME Seahorse

GNOME Seahorse, often labeled simply as "Passwords and Keys" in Linux desktop environments, serves as a centralized graphical interface for managing encryption keys, credentials, and keyrings. This article explains how Seahorse facilitates the creation, storage, synchronization, and deployment of GNU Privacy Guard (GPG) keys and Secure Shell (SSH) credentials, eliminating the need to manage these security assets solely through the command line.

What Is GNOME Seahorse?

Seahorse is the official GNOME application designed to interface with backend security frameworks, primarily GnuPG (gpg) and OpenSSH (ssh). Rather than replacing these core utilities, Seahorse acts as an intuitive front-end, interacting directly with the system's keyring daemon (gnome-keyring-daemon) to provide secure credential storage and simplified cryptographic operations.

Managing GPG Keys

GPG keys are widely used for signing data, verifying software packages, and encrypting email communications. Seahorse streamlines several critical GPG tasks:

  • Key Generation: Users can generate new PGP/GPG key pairs through a guided wizard, defining parameters such as key type (e.g., RSA or elliptic curves), key strength in bits, expiration dates, and owner identification details (name, email, and comment).
  • Key Properties and Trust Settings: Seahorse displays technical details such as key IDs, fingerprints, and subkeys. Users can modify trust levels, change passphrases, extend expiration dates, and revoke compromised or obsolete keys.
  • Keyserver Synchronization: The application integrates with public keyservers. Users can search for and import other individuals' public keys directly from the interface, or publish their own public keys so others can verify their signatures and send encrypted messages.
  • Import and Export: Public and private keys can be exported to text-based ASCII-armored files (.asc) for backup or distribution. Existing key files can also be dragged and dropped into the application to import them into the local GPG keyring.

Managing SSH Credentials

SSH keys are standard for authenticating to remote servers and services like GitHub or GitLab without relying on passwords. Seahorse simplifies OpenSSH workflows:

  • SSH Key Pair Creation: Seahorse allows users to generate new SSH identity files (both public and private components). It prompts for key types, comments, and optional passphrases for encrypting the private key on disk.
  • Deploying Keys to Remote Servers: A standout feature of Seahorse is the "Configure Key for Secure Shell" tool. This provides a graphical equivalent of the ssh-copy-id command, allowing users to enter a remote server's hostname and login credentials to automatically install their public key into the remote authorized_keys file.
  • Viewing and Copying Public Keys: Users can inspect the fingerprint of any SSH key and copy the raw public key string directly to the clipboard for pasting into web-based authentication settings.

Integration with GNOME Keyring and SSH Agent

Beyond manual management, Seahorse works alongside the background keyring services to enhance usability:

  • Passphrase Caching: When an SSH or GPG key is accessed, the GNOME Keyring daemon can securely store the decrypted passphrase in memory for the duration of a desktop session, preventing repeated password prompts.
  • Automatic Agent Forwarding: Keys managed within the desktop environment are made automatically available to ssh-agent and gpg-agent, ensuring consistent authentication behavior in both terminal sessions and graphical applications.
