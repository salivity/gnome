GNOME Disks: Partitioning, Benchmarking, and SMART Data

GNOME Disks (also known as gnome-disk-utility) is a versatile, graphical storage management tool for Linux that simplifies low-level disk operations. This article explores how the utility enables users to easily configure drive partitions, evaluate drive read and write speeds through integrated benchmarking, and inspect hardware health metrics using SMART data to prevent catastrophic drive failure.

Disk Partitioning and Drive Configuration

GNOME Disks provides an intuitive visual interface that displays all internal and external storage drives connected to the system. Managing partitions is accomplished without needing complex command-line utilities:

  • Creating and Deleting Partitions: Users can select unallocated space or existing volumes to create, format, or delete partitions. The utility supports numerous file systems, including ext4, Btrfs, XFS, FAT, and NTFS.
  • Resizing and Modifying Filesystems: Supported file systems can be expanded or shrunk directly from the application interface, provided the underlying file system supports online or offline resizing.
  • Automating Mount Options: GNOME Disks allows users to configure mount points and auto-mount behavior on system startup. This interface generates and edits entries in the /etc/fstab file safely without requiring manual text editing.
  • Disk Imaging: Users can create complete, byte-for-byte .img backup files of entire drives or individual partitions, as well as restore images back to a selected target device.

Storage Benchmarking

The built-in benchmark tool gives users an accurate measurement of drive performance under controlled conditions:

  • Read and Write Tests: Users can measure sustained transfer rates across the entire storage medium. Read tests can be run safely at any time, while write tests require unmounted, raw drives to prevent accidental data corruption.
  • Customizable Parameters: The benchmark suite allows customization of transfer sizes (e.g., 10 MiB samples) and sample counts to simulate different workload patterns, from sequential media transfers to random access.
  • Access Time Measurement: Alongside throughput, the tool measures access latency in milliseconds, helping users assess the responsiveness of traditional spinning hard drives (HDDs) versus solid-state drives (SSDs).
  • Visual Graphing: The utility charts the results over the capacity of the drive, clearly visualizing how rotational speeds affect HDD performance from the outer to the inner tracks.

SMART Data and Drive Health Monitoring

GNOME Disks reads Self-Monitoring, Analysis, and Reporting Technology (SMART) data directly from compatible ATA, NVMe, and SCSI storage controllers:

  • Health Assessment: The software displays an immediate, high-level status indicator (such as "Disk is OK") to alert users if any critical thresholds have been exceeded.
  • Detailed Attribute Inspection: Users can review granular metrics, including reallocated sector counts, spin retry counts, power-on hours, and current operating temperatures. Tracking these values over time helps detect early hardware degradation before total failure occurs.
  • Self-Tests: GNOME Disks allows users to trigger built-in drive diagnostic routines directly from the interface:
    • Short Self-Test: Checks electrical and mechanical performance alongside a small portion of the disk surface, usually completing within a few minutes.
    • Extended Self-Test: Reads the entire disk surface to identify damaged sectors and assess drive reliability under sustained load.
