GNOME Shell Dash: Running Apps vs Favorites

The GNOME Shell Dash acts as both an application launcher and a task switcher, dynamically balancing user-defined favorite applications with currently running processes. While favorite apps remain permanently pinned in a fixed order for quick access, running applications that are not pinned appear dynamically alongside them, distinguished by subtle visual separators and window indicators. Understanding how GNOME manages this separation clarifies how the desktop environment handles process tracking, multi-window navigation, and workspace context.

The Structure of the Dash

By default, the Dash appears when entering the Activities Overview, positioned along the left edge or bottom of the screen depending on the GNOME version. It is split into two primary categories:

  • Favorites (Pinned Applications): These are persistent shortcuts explicitly saved by the user. They remain on the Dash regardless of whether the application is currently open or closed.
  • Running Applications (Transient): Any launched application that is not explicitly pinned to favorites is temporarily added to the Dash.

Visual Separation and Order

GNOME organizes these two groups using spatial hierarchy and visual cues:

  1. Fixed Placement: Favorite apps occupy the primary section of the Dash, retaining the exact custom order defined by the user.
  2. The Divider Line: When an unpinned application is opened, GNOME Shell places a small, subtle horizontal or vertical divider line (depending on orientation) after the last favorite icon.
  3. Transient Placement: Unpinned running applications populate the space immediately following this divider line. They appear in the order they were opened and disappear automatically once the application process terminates.

Indicators for Running States

To distinguish between an idle favorite and an active application, GNOME uses dot indicators:

  • Closed Favorites: Display standard app icons with no accompanying marks.
  • Running Favorites: Display one or more small dots (or dashes) beneath or beside the icon. A single dot indicates an active instance, while multiple dots or an expanded indicator denote multiple open windows of that application.
  • Running Unpinned Apps: Always display the running indicator, as they only exist in the Dash while their process is active.
  • Focused Window: The currently focused application often features a highlighted or brighter indicator compared to inactive background applications.

Interaction and Context Menus

The Dash adapts its behavior and right-click context menus based on an application's status:

  • Launching and Switching: Clicking a closed favorite launches a new process. Clicking any running application (pinned or unpinned) brings its focused window to the front. If multiple windows are open, clicking the icon triggers an interactive window-picker preview.
  • Pinning from the Dash: Right-clicking an unpinned running application reveals the option to "Pin to Dash" (or "Add to Favorites"). Selecting this moves the icon across the divider into the favorites section, making it permanent.
  • Management: Right-clicking a running app provides options to quit all windows, select specific open windows, or open a new window instance. For favorites, it includes the option to "Remove from Favorites."
