GNOME Shell Screen Sharing and Recording Indicators

This article explains how GNOME Shell visually alerts users when an application is actively recording or sharing the screen. GNOME Shell prioritizes user privacy through distinct top bar icons, interactive Quick Settings controls, and system-level security prompts powered by modern Wayland and PipeWire standards.

The Top Bar Indicator

Whenever a screen capture session begins, GNOME Shell places a prominent visual indicator directly into the top panel's system status area.

  • Screen Recording: When the built-in screen recorder or an external recording utility is active, GNOME Shell displays a bright red or orange dot with an elapsed-time counter in the panel.
  • Screen Sharing: When sharing your screen via web browsers or communication software, an icon depicting a monitor or casting symbol appears in the top bar.

These persistent icons remain visible across all virtual workspaces, ensuring that background applications cannot silently capture the desktop without the user's knowledge.

Quick Settings Integration

Clicking the system menu (Quick Settings) in the top-right corner provides deeper context and direct control over active streams. When screen sharing or recording is underway, GNOME Shell inserts an active session banner at the top of the menu.

This banner explicitly names the application requesting the stream and displays a high-visibility button—typically labeled "Stop Sharing" or "Stop"—allowing you to immediately terminate the video feed with a single click without opening the client application.

Desktop Portals and Selection Prompts

Visual awareness begins before the capture even starts. Because GNOME Shell relies on xdg-desktop-portal-gnome and PipeWire for Wayland display management, applications cannot access display buffers directly.

Instead, GNOME Shell generates a system-modal dialog prompting the user to grant permission. This prompt includes visual thumbnails of available monitors or individual application windows, ensuring users explicitly verify what will be captured before the visual indicators in the top bar engage. In recent GNOME releases, selecting a single window or virtual monitor may also highlight the targeted region with a subtle border to clearly distinguish what is being broadcast.
