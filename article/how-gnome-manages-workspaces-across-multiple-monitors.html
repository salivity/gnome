How GNOME Manages Workspaces Across Multiple Monitors

The GNOME desktop environment handles window organization through an automated, dynamic workspace model paired with configurable multi-monitor behavior. Unlike traditional desktop interfaces that rely on fixed numbers of virtual desktops, GNOME automatically creates and destroys workspaces based on user demand while offering distinct settings to control whether these workspaces stay confined to the primary screen or span across all connected displays.

Dynamic Workspaces Explained

GNOME avoids the concept of a static number of virtual desktops. Instead, it continuously maintains an empty workspace at the end of the workspace list.

  • Automatic Creation: As soon as an application window is placed onto the trailing empty workspace, GNOME automatically instantiates a new empty workspace beneath or beside it.
  • Automatic Cleanup: When all windows are closed or moved off an intermediate workspace, GNOME removes that workspace immediately and collapses the remaining ones to keep the workflow compact and uncluttered.

Users can view and interact with these workspaces via the Activities Overview, which provides a horizontal or vertical carousel (depending on the GNOME version) allowing seamless drag-and-drop window management.

Multi-Monitor Workspace Behavior

When multiple monitors are connected, GNOME provides two primary modes of operation, configurable via the system settings:

1. Workspaces on Primary Display Only (Default)

By default, GNOME restricts dynamic workspace switching strictly to the designated primary monitor.

  • The primary display dynamically adds, removes, and cycles through workspaces as usual.
  • The secondary display (or displays) remain static. Applications placed on secondary screens remain visible regardless of which workspace is currently active on the primary display.
  • This mode benefits workflows where secondary monitors host persistent reference material, such as chat applications, system monitors, or documentation.

2. Workspaces Span Displays

GNOME can be configured to switch workspaces simultaneously across every connected screen.

  • Navigating to an adjacent workspace shifts the viewport on all connected monitors at the same time.
  • Each physical screen displays windows tied exclusively to that workspace index.
  • This behavior caters to context-switching workflows where an entire multi-monitor setup belongs to a single project or task.

Configuration and Controls

Workspace management settings can be configured through Settings > Multitasking:

  • General / Workspaces: Toggle between "Dynamic workspaces" and a fixed number of workspaces.
  • Multi-Monitor Handling: Choose between "Workspaces on primary display only" and "Workspaces on all displays."

Navigation

Workspaces can be navigated using standardized inputs regardless of monitor configuration:

  • Keyboard: Super + Page Up / Super + Page Down (or Super + Alt + Up / Super + Alt + Down depending on the GNOME version) cycles through active workspaces. Adding Shift to these shortcuts moves the focused window along with the viewport.
  • Trackpad Gestures: Three-finger horizontal or vertical swipes switch smoothly between workspaces.
  • Overview: Pressing the Super key opens the Activities Overview, where workspaces can be selected, reordered, or managed directly with the mouse.
