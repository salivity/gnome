How GNOME Shell Handles Multi-Monitor Workspaces

GNOME Shell manages multi-monitor workspace switching through two distinct operational modes: keeping workspaces confined to the primary display or spanning them across all connected screens. By default, GNOME isolates virtual workspace switching to the primary display while secondary monitors remain static, but users can configure workspaces to switch simultaneously across all screens depending on their workflow needs.

The Default Behavior: Workspaces on Primary Display Only

In the default configuration, GNOME Shell designates one screen as the primary monitor and confines virtual desktop switching strictly to that screen. Any secondary monitors act as fixed, persistent workspaces.

When you navigate between workspaces using touchpad gestures, the mouse scroll wheel in the top bar, or keyboard shortcuts (such as Super + Page Up / Super + Page Down or Super + Alt + Left / Super + Alt + Right depending on the GNOME version), only the windows on the primary display shift in and out of view. Windows placed on external or secondary monitors stay visible at all times, making this mode ideal for keeping reference material, system monitors, or communication tools permanently in view.

The Alternative Behavior: Workspaces on All Displays

GNOME Shell also supports a synchronized mode where workspaces span across all monitors simultaneously. In this configuration, switching to a new workspace changes the view on every connected display at once.

When enabled, workspace n consists of the combined desktop real estate of all connected monitors. Navigating to workspace n+1 simultaneously slides out all windows across every display, presenting an entirely fresh set of screens. This setup is favored by users who treat multiple monitors as a unified project canvas and prefer switching contexts entirely when moving between different tasks.

Configuring the Behavior

You can toggle between these two behaviors using the built-in system settings:

  1. Open Settings.
  2. Navigate to the Multitasking panel (available in GNOME 40 and newer).
  3. Locate the Multi-Monitor section.
  4. Select either Workspaces on primary display only or Workspaces on all displays.

The change takes effect immediately without requiring a shell restart or user logout.

Overview and App Switching Dynamics

The chosen workspace behavior also influences GNOME's "Activities Overview":

  • Primary Display Only: Entering the overview displays the workspace thumbnail strip exclusively on the primary monitor. Secondary screens zoom out to show their open windows for selection, but do not display workspace navigation elements.
  • Workspaces on All Displays: Entering the overview displays workspace navigation across the environment, allowing you to drag windows between different monitors and workspaces simultaneously.

The built-in application switcher (Alt + Tab) also respects your multitasking preferences, allowing you to configure whether it cycles through applications across all monitors or isolates switching only to the monitor that currently holds the input focus.
