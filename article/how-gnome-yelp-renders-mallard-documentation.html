How GNOME Yelp Renders Mallard Documentation

GNOME Help, known internally as Yelp, is the default documentation viewer for the GNOME desktop environment. Its primary purpose when working with Mallard-based documentation is to resolve, assemble, and render topic-oriented help files dynamically for end users. Unlike traditional static document viewers, Yelp processes Mallard’s decentralized XML files at runtime, transforming modular, context-driven help topics into a cohesive, easily navigable presentation.

Mallard is an XML schema specifically engineered for modern software documentation. Instead of relying on a rigid, linear book format with hardcoded chapters and tables of contents, Mallard uses a topic-oriented approach divided into "topic" pages and "guide" pages. In this architecture, documents define their relationships upstream through metadata rather than downstream through static menus.

Yelp acts as the rendering engine and navigation processor that brings this model to life. When a user launches help for an application, Yelp performs several critical tasks:

  • Dynamic Link Graphing: Yelp reads the metadata tags across individual Mallard page files to determine parent-child relationships and see-also cross-references. It computes the link hierarchy on the fly, automatically generating navigation links on guide pages without requiring documentation writers to maintain manual index pages.
  • Modular Extensibility: Because Mallard links dynamically, third-party extensions or add-ons can install their own help topics into an application's documentation directory. Yelp scans these directories, recognizes the new topic files, and automatically inserts them into the existing guide pages without modifying the original documentation source.
  • Content Transformation: Under the hood, Yelp leverages transformation stylesheets to convert raw Mallard XML into styled HTML. It then displays this output seamlessly using WebKitGTK, applying desktop-consistent CSS styling that matches the user's active GNOME system theme.
  • Context-Sensitive Help Support: Yelp provides the bridge between desktop applications and their corresponding help manuals. When a user requests context-sensitive help—such as pressing F1 within a specific dialog box—Yelp identifies the exact Mallard topic ID requested by the application and renders that specific page instantly.
  • Search and Indexing: Yelp processes the titles, text nodes, and indexing terms defined inside the Mallard files to provide an integrated desktop search interface, enabling users to find relevant problem solutions without browsing entire document trees.

By functioning as an active graph processor rather than just a passive reader, Yelp ensures that Mallard documentation remains modular, maintainable, and resilient against broken links across system updates.
