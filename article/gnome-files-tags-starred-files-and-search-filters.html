GNOME Files Tags, Starred Files, and Search Filters

GNOME Files, formerly known as Nautilus, provides an integrated system for organizing, prioritizing, and locating documents without relying solely on rigid directory trees. Through the combination of starred bookmarks for instant access, metadata-driven tagging via the underlying Tracker indexing engine, and dynamic contextual search filters, users can rapidly manage and retrieve data across local and remote storage.

Starred Bookmarks for High-Priority Files

GNOME Files replaces traditional ad-hoc tagging with a native "Starred" system designed for quick bookmarking. Users can star any file or folder by right-clicking the item and selecting the star option, or by toggling the star icon directly in the list view.

Once starred, items remain in their original directories but are aggregated globally under the "Starred" section in the left sidebar. This system operates as a unified virtual directory, allowing immediate access to critical files regardless of where they reside in the filesystem hierarchy. The metadata is tracked internally, ensuring that moving files within supported locations does not break the starred status.

File Metadata and Tagging via GNOME Tracker

Rather than maintaining a separate, isolated tagging database, GNOME Files leverages GNOME Tracker—a low-footprint search engine and metadata database. Tracker indexes files automatically, reading embedded tags and metadata such as EXIF data in photographs, ID3 tags in audio files, and author or keyword tags embedded within PDFs and office documents.

This deep indexing allows GNOME Files to recognize arbitrary semantic tags already baked into your files. When searching, these embedded tags function as primary identifiers, allowing users to query items based on embedded project names, topics, or categories without requiring manual tag configuration within the file manager interface.

Contextual Search Filters

The search functionality in GNOME Files activates automatically when a user starts typing within any active directory, or by pressing Ctrl + F. The search engine adapts contextually based on the user's current location, offering options to search either the active folder specifically or the entire system via indexed locations.

Beside the search bar, GNOME Files provides contextual drop-down filters to refine search queries without requiring complex syntax:

  • File Type Filters: Users can restrict queries to specific classifications, such as Documents, Images, Audio, Video, Folders, or Software.
  • Date Modified Filters: Results can be constrained by temporal ranges, including "Today," "Since Yesterday," "Last Week," "Last Month," "Last Year," or a custom date range.
  • Content vs. Name Matching: Thanks to Tracker integration, the contextual search queries both file names and the internal text content of documents. If an exact name match is not found, the search surfaces files containing the query string within the file body.

By coupling continuous background indexing with intuitive front-end filters and quick-access bookmarks, GNOME Files delivers a streamlined search and retrieval workflow tailored for modern Linux desktops.
