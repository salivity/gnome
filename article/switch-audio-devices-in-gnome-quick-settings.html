Switch Audio Devices in GNOME Quick Settings

This article provides a comprehensive overview of how modern GNOME desktop environments handle audio sink (output) and source (input) switching directly from the Quick Settings menu. Starting with GNOME 43, the desktop environment overhauled its system status area, introducing interactive sub-menus that allow users to manage their audio hardware seamlessly. Below, you will learn how to navigate this interface, switch audio outputs and inputs on the fly, and understand how GNOME communicates with the underlying sound server to redirect active audio streams.

Accessing Audio Output Sinks

GNOME places audio management front and center in its Quick Settings menu, accessible by clicking the system status icons in the top-right corner of the panel or by pressing Super + S.

Within the menu, the master volume slider controls the current default output sink (such as speakers, headphones, or HDMI outputs). To switch sinks:

  1. Open the Quick Settings menu.
  2. Locate the volume slider and click the arrow (>) button located immediately to its right.
  3. A sub-menu will open, listing all connected and detected audio output devices.
  4. Click on the desired device to select it as the new default output sink.

The switch takes effect instantly. An icon representing the newly selected device will replace the generic speaker icon in the slider row, providing immediate visual feedback.

Managing Audio Input Sources

To keep the interface clean, GNOME handles microphone and input sources contextually. The input volume slider only appears in the Quick Settings menu when an application is actively recording or monitoring audio (such as during a VoIP call, screen recording, or browser-based voice input).

When an audio source is active:

  1. Open the Quick Settings menu.
  2. Locate the microphone input slider, which appears below the output slider.
  3. Click the arrow (>) button on the right side of the input slider.
  4. Select the preferred microphone or line-in device from the list.

Once selected, all active recording streams are automatically rerouted to the chosen hardware source.

Underlying Mechanism: PipeWire and PulseAudio Integration

Behind the user interface, GNOME Shell relies on libgvc (GNOME Volume Control library), which communicates directly with the system's sound server—typically PipeWire on modern distributions, or PulseAudio on legacy installations.

When you select a different sink or source in the Quick Settings sub-menu, GNOME Shell sends an instruction to the sound server to change the system-wide default node. PipeWire or PulseAudio then dynamically moves all currently playing or recording media streams to the newly selected hardware node. This routing happens in real time without requiring applications to be restarted or interrupting active playback.
