How GNOME Software Displays Reviews and Ratings

GNOME Software provides an integrated, community-driven feedback system that displays user reviews and star ratings directly on an application's details page. By leveraging the Open Desktop Ratings Service (ODRS), GNOME Software aggregates feedback across multiple Linux distributions, giving users transparent insight into an application's stability, usability, and performance before installation.

Visual Placement and Rating Summaries

When a user opens an application's page within GNOME Software, the overall rating is prominently featured at the top near the application's icon, name, and installation button. This score is displayed as a five-star graphic accompanied by the average numerical rating and the total count of submitted reviews.

Below the main description and screenshots, the interface provides a dedicated "Reviews" section. Here, users can view a visual histogram breaking down the distribution of one- to five-star ratings, allowing potential users to gauge consensus quickly.

The Open Desktop Ratings Service (ODRS)

Unlike proprietary app stores that lock feedback behind closed vendor ecosystems, GNOME Software sources its ratings from the Open Desktop Ratings Service. This shared backend allows different desktop environments and distributions—such as Fedora, Ubuntu, and openSUSE—to pool reviews together. As a result, even niche open-source applications often have sufficient feedback volume, regardless of which specific distribution a user runs.

Review Cards and Version Context

Individual reviews are presented in reverse chronological order as distinct cards. Each review entry contains:

  • The star rating assigned by the reviewer.
  • A summary title and detailed commentary.
  • The date the review was posted.
  • The specific version of the application that was reviewed.

Displaying the application version is particularly crucial for open-source software, as bugs or missing features noted in older reviews may have already been resolved in subsequent releases.

Submission, Privacy, and Community Moderation

Users can submit their own reviews directly within the client if they have the application installed. To preserve user privacy, the ODRS does not require a traditional account login; instead, it uses an anonymized, cryptographically hashed machine ID to prevent duplicate submissions.

To maintain quality and reduce spam, GNOME Software includes built-in moderation controls. Users can mark reviews as helpful or unhelpful, or report abusive content. Reviews that accumulate negative moderation scores are automatically hidden from the public view, ensuring that constructive and relevant feedback remains front and center.
